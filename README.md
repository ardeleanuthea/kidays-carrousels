# Kidays · Carrousels (bêta)

Outil de l’équipe Kidays : on dépose un document (Word, PDF ou texte), il devient un carrousel Instagram 1080 × 1350 aux couleurs Kidays.
5 thèmes au choix, retouche des textes et des positions directement sur les diapos, export PNG.
Accès : identifiant + mot de passe, demandez à Thea.

L’application est **chiffrée** (`app.enc.json`) : sans mot de passe, le code n’est pas lisible.
